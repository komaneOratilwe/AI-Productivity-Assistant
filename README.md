# AI Workplace Assistant

Build a modern, responsive web application called "AI Workplace Productivity Assistant" 

that helps professionals automate workplace tasks using AI. Create a dashboard layout with 

a sidebar navigation containing 5 sections: Email Generator, Meeting Summarizer, Task Planner, 

Research Assistant, and AI Chatbot. Each section should be a separate page/view accessible 

from the sidebar. The main content area should show a welcome/overview screen by default. 

Design style: clean, modern, professional, similar to a SaaS platform (think Notion or Linear), 

using a blue and white color palette, rounded cards, and clear typography. Make it fully 

responsive for both mobile and desktop, with the sidebar collapsing into a hamburger menu on mobile.
